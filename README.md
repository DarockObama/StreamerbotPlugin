# Streamerbot Plugin

This plugin lets [Streamerbot](https://streamer.bot/) perform actions upon events happening in the game, using notifiers
from [Dink](https://github.com/pajlads/DinkPlugin/tree/master) through `HTTP` requests. 

### What is Streamerbot?

Streamerbot is a versatile, locally run and open-source tool used for streaming. It integrates various streaming
platforms such as Twitch, broadcasting software like OBS, among many other platforms and applications to perform
automated tasks for your streams. You can think of use cases such as:
- Sending messages to Twitch Chat
- Controlling OBS Studio
- Posting messages to Discord
- Playing text-to-speech Audio with [Speaker.bot](https://speaker.bot/).
